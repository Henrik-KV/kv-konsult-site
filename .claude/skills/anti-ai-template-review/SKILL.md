# Anti AI Template Review

Judge the rendered page as a whole. Avoiding robots or stock photography is not enough; a page can still be a generic consultancy template.

## Template signals to check

- excessive eyebrow labels or uppercase micro-headings;
- repetitive cards or equal-sized content modules;
- repeated numbered blocks where sequence is not necessary;
- generic SVG workflows, nodes, dashboards, or process diagrams;
- oversized slogan typography used instead of information;
- unnecessary arrows, slashes, badges, pills, and technical captions;
- generic gradients or glow used as the primary personality;
- fake console, status, system, or interface language;
- the standard cadence of hero, three services, process, audiences, cases, team, CTA;
- three equal service columns for Utbilda, Införa, Bygga;
- AI-sounding slogan chains, short fragments, false oppositions, or repeated full stops;
- abstract graphics presented before real work;
- mobile that merely stacks the same modules.

## Review method

1. List every signal present in the rendering and copy.
2. Identify which sections could be moved unchanged to another consultancy.
3. Check whether real work, people, and verified material create the identity early enough.
4. Check whether one item is allowed to dominate instead of every dataset becoming a grid.
5. Check whether decoration communicates something or merely makes ordinary text look designed.
6. Recommend the smallest structural correction, not more decoration.

## Verdict

Use `PASS`, `PARTIAL`, or `FAIL`. A pass requires no dominant template pattern. If the same cadence or equal modules still organise the page, fail it even when typography and colour are polished.

Never use self-congratulatory labels to describe the result. Name remaining generic patterns explicitly.
