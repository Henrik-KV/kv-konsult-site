# Anti-template rules

Reject a section if its main structure could be moved unchanged to another AI consultancy.

## Do not use

- eyebrow labels on every section;
- repeated rounded cards or equal content modules;
- numbered navigation or numbering without real sequence;
- default three-column service grids;
- generic node, document, dashboard, process, or workflow SVGs;
- oversized slogans standing in for explanation;
- arrows on ordinary links;
- pills, badges, fake status labels, console language, or slash-heavy captions;
- gradients or glow without a relationship to real work or the KV mark;
- hero → three services → process → audiences → cases → team → CTA as an unquestioned cadence;
- copy made of repeated short fragments and full stops;
- abstract proof before verified interfaces or deliverables;
- mobile layouts created only by stacking desktop modules.

## Use instead

- natural Swedish sentences;
- one dominant item and clearly secondary support;
- verified product screens and accurately labelled demos;
- direct access to real people;
- varied section rhythm with fewer section headlines;
- colour derived from the requested white/light-blue KV expression;
- motion that changes understanding, not decoration;
- a mobile reading order designed independently.

## Approval question

Would the page still look specifically like KV Konsult if the logo were temporarily hidden? If not, the direction is not ready.
