# Visual rejection of the current Preview

Preview reviewed: `https://kv-konsult-site-git-redesign-k-1a3d30-henriks-projects-c5eb59d1.vercel.app`

- Technical verdict: largely pass
- Visual verdict: fail
- Client-readiness verdict: not safe to show

This document reviews the rendering, not its implementation quality.

## Captures

- [Desktop, 1440×900](visual-rejection/current-preview-desktop-1440x900.png)
- [Mobile, 390×844](visual-rejection/current-preview-mobile-390x844.png)

## Desktop annotations

- **D1 — Header:** the logo is reduced to a tiny square, navigation has insufficient brand presence, and the underlined CTA with a trailing symbol feels like an agency prototype.
- **D2 — Hero:** category label, oversized slogan, two CTAs, grid background and workflow panel reproduce a familiar AI-consultancy formula.
- **D3 — Hero visual:** the node-and-document diagram looks custom but remains generic technology theatre. It is weaker evidence than the real app shown later.
- **D4 — Capability model:** Utbilda, Införa and Bygga are three equal cells with near-identical anatomy. The hierarchy is a grid, not an argument.
- **D5 — Scroll story:** a sticky left diagram and four right-hand stages create a very large pale void. The page spends disproportionate height explaining a generic define/build/follow-up sequence.
- **D6 — Audiences:** municipalities and companies become two equal columns with almost the same visual weight and repeated list treatment.
- **D7 — Work:** Lägesbild and MÄSSY arrive too late. The dark centre panel underuses the real screenshots and weakens the proof.
- **D8 — Team:** three names become numbered rows in a table. Direct contact is useful, but the treatment is impersonal.
- **D9 — CTA/footer:** the final dark band is another oversized slogan surface; the footer repeats the small-logo problem.

### Desktop screenshot critique

- Strongest element: real work is labelled accurately, including MÄSSY as a demo.
- Weakest element: the four-stage scroll section creates a long, empty, low-information middle.
- Generic-template signals: micro-eyebrows, oversized headline, equal modules, workflow SVG, sequence numbers, arrow-like link decoration and repeated section slogans.
- Hierarchy problems: abstract explanation dominates before real proof; too many headings compete at near-equal scale.
- Spacing problems: uniform editorial spacing and oversized section heights create monotony instead of rhythm.
- Copy problems: short slogan constructions sound manufactured and repeat the same cadence.
- Mobile-specific problems: not applicable to this capture.
- Safe to show client: no.

## Mobile annotations

- **M1 — Header:** the tiny logo and generic hamburger do not create a premium first impression.
- **M2 — Hero:** the slogan wraps into a familiar marketing block; the abstract diagram still consumes the main evidence position.
- **M3 — Capabilities:** the equal desktop grid becomes three equal stacked modules inside one rounded container.
- **M4 — Scroll story:** desktop pinning becomes a long sequence of large text blocks with little visual change. The user must scroll far before reaching audience or proof.
- **M5 — Audiences:** the two-column comparison becomes two long, similar text stacks.
- **M6 — Work:** the project presentation becomes a tall framed object with large empty/dark zones before the screenshots become useful.
- **M7 — Team:** numbered contact rows remain formal and remote instead of human.
- **M8 — CTA/footer:** another large dark slogan block is followed by a long utility footer, extending an already overlong page.

### Mobile screenshot critique

- Strongest element: readable type and no obvious horizontal overflow in the rejected build.
- Weakest element: the page is a desktop sequence stacked vertically, producing excessive length and repeated rhythm.
- Generic-template signals: eyebrow labels, equal service stack, numbered process, abstract workflow, slogans before sections, decorative link symbols.
- Hierarchy problems: proof and people arrive too late; the first several screens repeat explanation.
- Spacing problems: large blank intervals in the scroll story and excessive vertical padding.
- Copy problems: headings remain slogan-led and self-conscious; natural explanatory Swedish is secondary.
- Mobile-specific problems: generic hamburger, awkward long heading wraps, repeated modules, overlong story, weak first-screen proof.
- Safe to show client: no.

## Conclusion

The current direction is not a base for polishing. Gate 1 replaces its composition before any further homepage implementation.
